# Agent E Independent Evidence

Owned local loopback proof only. All candidates retain NO-GO. No architecture,
gate or production acceptance is authorized by a captured command completing.

- `reproduce.mjs`: run directly under the shared fixture flock; exact child
  commands, times, overrides, exit codes and output hashes are captured per mode.
- `prepare/`: immutable65-case extraction, six harness regression tests, fixture
  installation/audits and retained Pingora source/binary binding.
- `pingora/`, `hyper/`, `envoy/`: independent full75 lab/evaluator output and
  runtime logs. Lab/evaluator exit1 is expected mandatory failure evidence.
- `hyper-build/`: fresh local target/cache optimized locked build, fmt, clippy,
  four tests, exact audit and86 published-archive/source comparisons. Only crate
  archives/index were copied read-only; no sibling build/source was modified.
- `published/`: independently fetched Pingora0.9.1 published archive/selected
  source verification against Cargo.lock and installed registry bytes.
- `image-review/`, `image-binding/`: pinned Envoy/Trivy version and findings,
  SBOM, image inspection and manifest/config/ordered-layer identity verification.
- `origin-calibration.json`: actual H1 versus native H2 byte-listener coverage.
- `envoy-benchmark/`: actual container PID resource workload separate from the
  shared harness's adapter-only Envoy CPU/RSS observations.
- `review-summary.json`: exact committed candidate/source/harness hashes,
  required failures, functional observations, audit/image scope and retained
  historical runs. `SHA256SUMS` binds reviewer evidence and the final report.
- `final-check/`: scoped redacted secrets scans and whitespace checks only;
  root owns full integrated checks, security scan and hosted CI.

Fixture PKI, private keys, crate archives/cache, binaries and exported Docker
image remain in ignored owner-only `.local`; they are not committed. Synthetic
HTTP corpus requests/responses are intentional test evidence. No third-party
load/security requests, real DNS/billing/cloud or production operations occur.

Historical failed/incomplete/invalid attempts remain in A/B/C/D committed
evidence and are indexed or described by the report; no later run erases them.
The reviewer full75 reproductions execute once per fresh candidate run root.
No protocol negatives or security scans are excluded or suppressed.
